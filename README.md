#Pong Game using Python Turtle

This is a simple **Pong Game** built using **Python** and the **Turtle graphics library**.  
The project is created for learning Python basics, object-oriented programming, and simple game development concepts.

---

## 🎮 About the Game

Pong is a classic two-player game where each player controls a paddle.  
The goal is to hit the ball back to the opponent and score points when the opponent misses the ball.

The first player to reach the selected score limit wins the game.

---

## 🕹️ Controls

### Left Paddle
- `W` – Move Up
- `S` – Move Down

### Right Paddle
- `↑ Arrow` – Move Up
- `↓ Arrow` – Move Down

---

## ⭐ Features

- Two-player gameplay
- Ball collision with walls and paddles
- Angle-based ball movement
- Increasing ball speed
- Center dashed line
- Scoreboard with score limit
- Game Over screen

---

## ▶️ How to Run the Game

1. Make sure Python 3 is installed
2. Download or clone this repository
3. Open the project folder
4. Run the game using:

```bash
python main.py
````

---

## 📁 Project Files

* `main.py` – Main game loop
* `ball.py` – Ball movement and physics
* `paddle.py` – Paddle controls
* `scoreboard.py` – Score display and game over logic
